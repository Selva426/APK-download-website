How to install

  1. Open this page in Chrome on your Android phone and tap Download.
  2. When the download finishes, tap the file.
  3. If asked, allow Install unknown apps for Chrome, then go back and tap Install.
  4. If Play Protect warns you, tap Install anyway. The apps aren't on the Play Store.

FAQ

Why the security warning?

Android warns about any app that doesn't come from the Play Store. The source code for these apps is public on GitHub.

Does it work on iPhone?

No, these are Android-only.

Will an update keep my data?

Usually yes. If an update fails to install, back up from inside the app, uninstall, then install the new version.
